# Public authority metadata

This directory retains only the public authority manifest, CA certificate, recorder public key, and witness public key referenced by the historical prototype profile. It contains no private keys.

The historical SmolLM2 alternative-model notes, local capacity observations, and self-attested candidate records are not part of this public source snapshot. Their originals remain in the local review candidate.

These files identify local prototype authorities; they do not establish independent trust or host-wide rollback protection. A new deployment needs owner-managed private authorities and a freshly admitted profile.
